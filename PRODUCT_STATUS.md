# VIBE private product preview

Brand provisional. Generic event marketplace identity; running is the first vertical.

Working: responsive discovery and distance/city/date filtering, event detail, multi-athlete mock checkout with shirt choice and upsell, Pix/card fee calculation, durable private workspace via D1 per authenticated Sites viewer, manual race results and distance chart, printable report, favorites, individual demonstration QR vouchers, manual code lookup and browser-native camera QR detection when available, separate shirt/kit delivery per athlete, shop delivery with seven-day date, cancellation request tracking, settings and draft invites.

Explicit demonstration boundary: fictional events, no real gateway charges, refunds, settlement, live inventory reservations or scheduled lot transition. No cross-account athlete claims, delegation or ticket transfer yet. Management tabs preview personas in one isolated viewer workspace; not a production multitenant authorization model. Public consumer authentication, gateway, timing API, messaging, contractual policies, organization event editor, store product CRUD/uploads and real access invitations are next integration work. Do not open this site to commercial use until those layers are implemented and verified.
